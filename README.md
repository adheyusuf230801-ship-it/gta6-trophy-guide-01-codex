An offline web guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with a guide to every trophy, a roadmap to the platinum, missable flags, saved progress with export and import, filters and a spoiler setting.

## Run it

```sh
node serve.ts, then open http://localhost:8080 — or open app/index.html directly in a desktop browser
```
